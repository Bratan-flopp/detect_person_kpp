# Обнаружение человека.
Комментарии и прочие подсказки есть в самом файле, а дописать дополнительно:
1.Ловит лишнее / ложные люди  подними conf
2.Пропускает людей  опусти conf или подними imgsz
3.Тормозит  опусти imgsz
4.Слишком быстро/медленно фиксирует выход  меняй EXIT_TIMEOUT
STREAM_URL желательно указывать IP, которое вывело Ваше Esp32-CAM в Serial Monitor.
Обнаружение человека это громко сказано. YOLO может отслеживать человека и потенциально можно реализовать КПП, отслеживать автомобили и прочие функции.
